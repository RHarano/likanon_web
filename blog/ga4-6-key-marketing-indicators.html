    GA4で見るべき集客の6つの指標

    GA4（Google Analytics 4）を開いても「どの数字を見ればいいか分からない」という方に。集客改善に本当に効く指標は6つだけです。個人事業主・小規模店舗が今日から使えるよう、画面の場所・目安値・改善アクションまで一気に解説します。

    はじめに：GA4は6つの指標だけで十分

    GA4のレポート画面には数百の指標が並びますが、集客改善のために毎月見るべきものは6つだけ。全部を追いかけようとするから挫折します。この記事では、その6つに絞って「どこを見て」「どう判断し」「何を直すか」を順番に解説します。

    対象は月間セッションが1,000未満の個人事業主・小規模店舗。改善サイクルは月1回で十分です。準備するものは、GA4のアカウントと、この記事だけ。

    指標1. セッション数（訪問数）

    見る場所：レポート → 集客 → 概要 の左上「セッション」

    そもそもHPに人が来ているかを見る、いちばん基本の数字です。月間セッションが100未満なら「見せる」以前に「集める」の課題があります。SEO・MEO・SNS導線の見直しから始めます。

    • 月間セッション50未満：集客導線がほぼ機能していない
    • 50〜200：MEOと指名検索でギリギリ回っている
    • 200〜500：地域集客の基本ラインは通過
    • 500以上：CVR改善に軸足を移してよい

    前月比で±10%は誤差の範囲。±20%以上動いたときだけ「何かあった」と判断するのがコツです。

    指標2. エンゲージメント率

    見る場所：レポート → エンゲージメント → 概要 の「エンゲージメント率」

    「10秒以上滞在した／2ページ以上見た／コンバージョンした」訪問の割合。旧アナリティクスの直帰率とは逆で、高いほど良い指標です。目安は60%以上。50%を割っていれば、入ってすぐ帰られている状態です。

    • 70%以上：ターゲット・見出しがハマっている
    • 60〜70%：合格ライン
    • 50〜60%：ファーストビュー要見直し
    • 50%未満：ターゲット設定からズレている可能性

    エンゲージメント率が低いときに直すのは、デザインではなく「トップの見出し」。「地域名＋業種＋対象者」に書き換えるだけで、5〜10ポイント動くことがあります。

    指標3. 平均エンゲージメント時間

    見る場所：レポート → エンゲージメント → 概要 の「平均エンゲージメント時間」

    読まれている時間の平均値。目安は1分（60秒）以上です。

    時間状態やるべき改善
    30秒未満ほぼ読まれていない見出しと冒頭150文字の書き直し
    30〜60秒斜め読み小見出しと箇条書きの追加
    1〜3分合格CTA位置の最適化
    3分以上読まれているが動かない問い合わせボタンの表現見直し

    時間が長いのにコンバージョンが少ないときは、「読み物として面白いが、次の一歩が示せていない」状態です。

    指標4. コンバージョン数（キーイベント）

    見る場所：レポート → エンゲージメント → コンバージョン

    GA4では「コンバージョン」は「キーイベント」と呼び方が変わりました。個人事業主なら、次の3つをキーイベントとして設定しておけば十分です。

    • 問い合わせフォーム完了ページ（thanks.html等）への到達
    • 電話番号タップ（tel:リンククリック）
    • LINE公式アカウントの友だち追加ボタンクリック

    設定手順：管理 → イベント → イベントを作成 → 上記のURLやクリック要素を条件に指定 → キーイベントとしてマーク。設定後は必ずテスト送信で計測されているか確認してください。ここがズレていると、後の全ての数字が意味を失います。

    指標5. コンバージョン率（CVR）

    見る場所：「コンバージョン数 ÷ セッション数」を電卓で計算

    GA4は直接CVRを表示しないので、自分で割り算します。目安は業種によって差がありますが、地域集客系なら2〜5%が合格ライン。

    • 0.5%未満：問い合わせ導線が機能していない
    • 0.5〜1.5%：ボタン位置と表現の見直しが効く
    • 2〜5%：合格
    • 5%以上：優秀。次はセッション数を増やすフェーズ

    CVRを改善する順序は、①電話・予約ボタンの位置 → ②お客様の声の追加 → ③料金目安の掲載 → ④FAQの設置、が定石です。

    指標6. 流入元（トラフィック獲得）

    見る場所：レポート → 集客 → トラフィック獲得

    誰が、どこから来ているかの内訳です。地域集客なら次のバランスが理想。

    流入元意味理想の割合
    Organic SearchGoogle・Yahoo自然検索40〜60%
    DirectURL直入力・ブックマーク15〜30%
    Organic SocialInstagram・LINE等10〜25%
    Referral他サイトからのリンク5〜15%

    Directが70%を超えている場合は「新規流入が弱く、既存顧客ばかり」の状態。SEOかSNSのどちらかを強化する必要があります。逆にSocialだけが突出していると、SNSが止まった瞬間に集客が止まるリスクを抱えています。

    初期設定の必須3項目

    GA4を入れたはいいが「デフォルトのまま」という個人事業主が非常に多いです。次の3つは必ず設定してください。

    1. データ保持期間を14ヶ月に延長：管理 → データ設定 → データ保持 → 「イベントデータの保持」を14ヶ月に。デフォルトは2ヶ月で、これでは前年比が取れません。
    2. Search Consoleと連携：管理 → プロダクトのリンク → Search Consoleのリンク。これで検索キーワードがGA4上で見られるようになります。
    3. 内部トラフィックの除外：管理 → データストリーム → タグ設定を行う → 内部トラフィックの定義。自宅・店舗のIPを登録すれば、自分のアクセスが数字から除外されます。

    この3つを終えてから、初めて「毎月の数字を判断する」フェーズに入れます。

    月次で見る5分ルーティン

    毎月1日、5分だけGA4を開く習慣を作ります。見るのはこの順番。

    1. レポート → 集客 → 概要 で「セッション数」を確認、前月比を見る
    2. レポート → エンゲージメント → 概要 で「エンゲージメント率」「平均エンゲージメント時間」を確認
    3. レポート → エンゲージメント → コンバージョン で「キーイベント数」を確認
    4. コンバージョン数 ÷ セッション数 でCVRを計算、目安値と比較
    5. レポート → 集客 → トラフィック獲得 で流入元バランスを確認

    これをExcelかスプレッドシートに毎月転記するだけで、半年後には立派な集客レポートができあがります。

    数字が動いた時の読み方

    数字は単発では意味を持ちません。「どこが動いた時に、何が起きているか」の型を覚えます。

    • セッション減 × CVR横ばい：集客源のどれかが落ちた（SEO順位・SNS投稿頻度・広告停止など）
    • セッション横ばい × CVR減：HP側の情報が古くなった・競合が価格を下げた
    • セッション増 × CVR減：ターゲット外の流入が増えた（キーワードのズレ）
    • 両方増：順調。今の施策を続ける
    • 両方減：季節要因か、大きな環境変化。慌てず1ヶ月様子見

    この5パターンで、月次の変動はほぼ説明が付きます。

    やってはいけない4つの落とし穴

    • 日次で数字を見る：ブレが大きすぎて判断を誤ります。最低週次、できれば月次で。
    • ユーザー数とセッション数を混同：ユーザーは「人」、セッションは「訪問回数」。集客改善はセッションを見ます。
    • 「新規ユーザー」だけを追う：リピーターの増減も同じくらい重要。両方の推移を見ます。
    • 目標を「セッション数」に設定：数字は増えても問い合わせは増えない典型パターン。目標はコンバージョン数に置きます。

    Search Consoleとの合わせ技

    GA4だけでは「検索されたキーワード」が分かりません。ここはSearch Consoleの領域です。両方見て初めて集客の全体像が把握できます。

    • Search Console：どんなキーワードで表示・クリックされたか
    • GA4：クリック後、何をして帰ったか

    Search Consoleで「表示回数は多いのにクリックが少ない」キーワードは、タイトルとメタディスクリプションの改善が効きます。GA4で「クリックは多いのに滞在時間が短い」ページは、本文と見出しの改善が必要です。

    3ヶ月移動平均で「本当の変化」を見る

    月次データを1ヶ月単位で見ると、たまたまの外れ値に振り回されがちです。そこで有効なのが「3ヶ月移動平均」。今月・前月・前々月の3ヶ月分を平均した値を使うと、ノイズが減り、本当のトレンドが見えます。

    • 単月：512 → 385 → 620 とジグザグ
    • 3ヶ月移動平均：480 → 505 → 506 と安定

    スプレッドシートで隣の列に「=AVERAGE(B2:B4)」を入れるだけ。半年ぶん蓄積すれば、季節性や施策効果が驚くほど明快に見えるようになります。

    GA4の探索レポートは後回しでいい

    GA4には「探索」という高機能なカスタムレポート機能がありますが、個人事業主が最初から触る必要はありません。標準レポートの6指標だけで判断可能な段階を、まず数ヶ月続けます。

    • 標準レポートで「ここが分からない」と具体的な不足を感じてから
    • 探索レポートは「ランディングページ別CVR」など特定の問いに答えるために使う
    • 最初から凝ると継続できずに終わる典型パターンにハマる

    ツールに合わせて使いこなすのではなく、判断に必要な分だけ機能を追加する順序が結局は早道です。

    業種別・重点的に見るべき指標

    業種によって、6つのうちどれを重視すべきかは変わります。

    • 飲食店・カフェ：流入元（Organic SearchとMap経由）、コンバージョン（電話タップ）
    • 整体・治療院：エンゲージメント時間、CVR（予約フォーム完了）
    • 美容室・サロン：流入元（Instagram経由の割合）、コンバージョン（予約タップ）
    • 士業（税理士・社労士）：エンゲージメント率、CVR（問い合わせフォーム）
    • 教室・スクール：平均エンゲージメント時間、コンバージョン（体験申込）

    よくある質問

    Q. GA4で最初に見るべき指標は？
    A. セッション数・エンゲージメント率・コンバージョン数の3つ。この順に確認していけば大枠が掴めます。

    Q. データはいつから見始めればいい？
    A. 設定から最低2週間、できれば1ヶ月経ってから。それ以下だとブレが大きく傾向が読めません。

    Q. GA4は無料？
    A. 完全無料。月間10億イベントまでの無料枠があり、個人事業主規模ならまず超えません。

    Q. 直帰率はどこで見られる？
    A. GA4では「エンゲージメント率」の裏返し（100 − エンゲージメント率）です。個別に見る必要はありません。

    Q. スマホでGA4を見るには？
    A. Google Analyticsアプリ（iOS・Android）が公式配布されています。通勤中や休憩時にサッと確認するのに便利です。

    アプリ通知とレポート自動化の活用

    「毎月見に行く」のを忘れる方は、GA4の「インサイト」機能とメール通知を活用します。設定は管理画面のインサイトから。あらかじめ用意された「今月のセッションは前月より+X%」といったカスタムインサイトを購読すると、Gmailに月次で通知が届くようになります。

    • 「先週と比較してユーザーが+20%以上」などの条件を設定
    • 異常値検出：予測値から大きく外れた日を自動で通知
    • Google Analyticsアプリ（iOS・Android）で通勤中に確認
    • Search Consoleの「メール レポート」も同時に有効化

    数字を追う仕組みを自動化しておくと、「気づいたら3ヶ月見ていない」という失敗を防げます。忙しい個人事業主ほど、この仕組み化の恩恵が大きくなります。

    まとめ

    GA4は6つの指標で十分です。セッション・エンゲージメント率・エンゲージメント時間・コンバージョン・CVR・流入元。これを月1回、5分だけ確認する習慣を付ければ、感覚ではなく数字で集客判断ができるようになります。

    大切なのは「たくさん見ること」ではなく「見た数字を打ち手につなげること」。6つの指標がどう動いたら何を直すかの型を、この記事の内容で身につけてください。
