集客数と成約率、どちらから改善すべきか

「アクセスを増やすべきか、CVRを上げるべきか」で迷って手が止まる方に。判断のフローチャート・数字の目安・具体的な打ち手を、個人事業主・小規模店舗の現実に合わせて解説します。順番を間違えると、労力の8割が無駄になります。

結論：まずCVRから改善する

先に結論。基本はCVR（成約率）が先、集客数はその後です。理由は単純で、CVRが低い状態で集客数を増やしても、投じた労力に見合う成果が出ないからです。

穴の空いたバケツに水を入れても溜まらないのと同じ。まず穴（低CVR）を塞いでから、水（アクセス）を注ぎます。

なぜCVRが先なのか：数字で見る

具体的な数字で示します。同じ「問い合わせ4件」を目指す2つのシナリオを比較します。

アプローチセッションCVR問い合わせ
集客数を増やす800（4倍）0.5%4件
CVRを上げる2002.0%（4倍）4件

どちらも問い合わせ4件ですが、必要な労力がまったく違います。セッションを4倍にするにはSEO・SNS・広告など数ヶ月がかりの施策が必要。一方CVRを4倍にするのは、ボタン位置・見出し・お客様の声の追加で、多くの場合1ヶ月以内に達成できます。

判断フローチャート

あなたの現在地に応じて、次のどちらを優先すべきかを判断します。

  1. 月間セッション50未満：集客数の底上げが先。まずMEOとSNS導線を整える。
  2. 月間セッション50〜200：CVRが2%以上あるか確認。2%未満ならCVR改善が先。
  3. 月間セッション200以上・CVR 2%未満：迷わずCVR改善から。
  4. 月間セッション200以上・CVR 2%以上：集客数の拡大フェーズへ。
  5. 月間セッション500以上・CVR 3%以上：単価向上・LTV改善のフェーズへ。

ここでいうセッションはGA4の「レポート → 集客 → 概要」で見られる月間セッション数。CVRは「キーイベント数 ÷ セッション数」で自分で計算します。

CVR改善が先なケースの見極め

「CVRが低い」ときの特徴は次の通り。ひとつでも当てはまればCVR改善が先です。

  • 月間セッションはあるのに問い合わせが月0〜1件
  • 電話ボタンが探さないと見つからない
  • ファーストビューで「誰向けの店か」3秒で伝わらない
  • お客様の声が1件も掲載されていない
  • 料金の目安がどこにも書かれていない
  • 問い合わせフォームの必須項目が7個以上ある

これらは全て「アクセスは来ているが、行動につながっていない」状態のサイン。集客数を増やす前に、まずここを直します。

集客数改善が先なケースの見極め

逆に「集客数が絶対的に足りない」ときの特徴。

  • 月間セッションが50未満
  • Googleビジネスプロフィールが未登録・情報未記入
  • 「地域名 ＋ 業種」の検索で3ページ目以降
  • Instagram・LINE公式などSNS導線がない
  • 他サイトからの被リンクがゼロ

この状態では、そもそもCVRを測るサンプル数が足りず、改善の効果測定もできません。まず「見つけてもらう」入り口を作ります。

ステップ1：CVR改善（1〜4週目）

CVR改善は次の4週間で組みます。

  1. 1週目：問い合わせボタンをヘッダー・スマホ画面下部に固定表示
  2. 2週目：トップ見出しを「地域名＋業種＋対象者」に書き換え
  3. 3週目：お客様の声を5件掲載（顔写真・日付付き）
  4. 4週目：料金の目安を表形式で掲載＋フォーム項目を3つに削減

この4週間で、地域集客系ならCVRは2%を超えるケースが大半です。

ステップ2：集客数改善（5〜12週目）

CVRが2%を超えたら、次はアクセスを増やすフェーズ。順序はこの通り。

  1. 5〜6週目：Googleビジネスプロフィールの完全記入＋写真週1追加
  2. 7〜8週目：お客様に口コミ依頼（月3件を目標）
  3. 9〜10週目：ブログを月1本開始（地域名＋悩み系キーワード）
  4. 11〜12週目：Instagramの投稿頻度を週2〜3回に

MEO → 口コミ → ブログ → SNS の順で積み上げるのが、費用ゼロで最速のルートです。

ステップ3：再度CVRを確認（13〜16週目）

集客数が増えた後は、必ずCVRを再チェックします。ここで数字が下がっていることがあります。

  • 新しい流入元（例：Instagram経由）はターゲット層と合っているか
  • ブログから流入した人向けの導線（記事下のCTA）は機能しているか
  • SNS経由の訪問者向けに、専用のランディングページが必要ではないか

集客源が増えると、それぞれの経路ごとに最適化が必要になります。この段階でようやく「集客源別のCVR分析」が意味を持ちます。

数字で見るBefore/After事例

事例1：整体院（CVR先行型）
改善前：セッション200／問い合わせ1件／CVR 0.5%。ここで広告を回したくなるところを踏みとどまり、ボタン位置・見出し・お客様の声の3点を4週間で修正。結果、セッション205（横ばい）・問い合わせ5件・CVR 2.4%へ。同じアクセスで問い合わせ5倍という典型パターン。

事例2：美容室（集客先行型）
月間セッション30、CVR測定不可能。まずMEO整備＋Instagram連動から着手。3ヶ月でセッション180、CVR 3.2%へ。この規模から入るとCVR測定より「まず集客の底上げ」が正解になります。

事例3：士業（両方停滞型）
セッション350、CVR 1.6%が半年以上横ばい。ポジション再定義（相続専門に絞り込み）から取り組み、対応する記事とページを整備。6ヶ月後にセッション420、CVR 3.4%へ。数字より「誰向けか」を再定義したのが効いた例です。

典型的な失敗パターン3つ

失敗1：CVRを整えずに広告を回す
月10万円広告を入れて500セッション、CVR 0.5%で問い合わせ2〜3件。同じ広告費でも、CVRが2%あれば10件になったはずのケース。広告は「増幅装置」なので、元のCVRが低いと損失も増幅されます。

失敗2：SNSでフォロワーを増やすことに全力
Instagramのフォロワー1,000人達成しても、HPへの流入がゼロならCVRを測ることさえできません。フォロワー数はCVには直結しません。プロフィール欄からHPへの導線を作ることが先です。

失敗3：CVRだけ追いかけて集客源が枯れる
CVRが5%になっても、月間セッションが30なら問い合わせは1〜2件。ある地点でCVR改善は頭打ちになるので、そこからは集客数を増やす段階に切り替えます。

「集客数を増やす」の中にも順序がある

ステップ2の集客数改善も、闇雲に手を広げると効果測定不能になります。個人事業主の場合、次の順で1つずつ進めるのが定石。

  1. MEO（Googleビジネスプロフィール）：費用ゼロ、最速2週間、地域集客の起点
  2. 口コミ収集：MEOの評価と信頼性を同時に強化
  3. ブログ（月1本）：SEO資産、3〜6ヶ月かけて花開く
  4. SNS（Instagram or LINE）：継続前提、業種と相性のいい方だけ
  5. 広告：CVRとMEOが整ってから、期間限定でテスト

MEOと広告を最初から並行、というやり方は費用対効果が最悪です。無料でできることを先に、有料は最後、が鉄則。

両方同時にやってはいけない理由

「時間があるから両方やる」は個人事業主にとって危険な判断です。

  • 効果が出た時に、どちらの施策が効いたか分からない
  • 労力が分散して、どちらも中途半端に終わる
  • 数字の分析ポイントがブレて判断ができない
  • 結果が見えないためモチベーションが続かない

1ヶ月ずつ「CVR → 集客 → CVR」と交互に切り替えるのが、最も学習も成果も積み上がります。

業種別・最初にやるべき改善

  • 飲食店：MEO（写真・営業時間・メニュー写真）→ 電話タップCVR確認
  • 整体・治療院：お客様の声・症状別ページ → MEO
  • 美容室：Instagram連動 → 予約フォームCVR
  • 士業：料金体系明示・実績掲載 → SEO
  • 教室：体験レッスン申込導線 → SNS + MEO
  • 小売店：Googleマップ・商品写真 → SNS連動

業種によって「CVRのボトルネック」と「集客源の適地」が違うため、順序も微調整が必要です。

「無料の集客源」を使い切ってから有料へ

予算がある方ほど、順序を飛ばして広告から始めがちですが、これは費用対効果を大きく損ないます。無料でできることを先に、有料は最後、が集客改善の鉄則です。

  • 費用ゼロ・即効性あり：Googleビジネスプロフィール、口コミ依頼、既存客への案内
  • 費用ゼロ・中期で効く：SEO記事、SNS投稿、被リンク獲得
  • 費用少・短期で測れる：Google広告、Meta広告（テスト期間限定）
  • 費用大・戦略投資：本格的な広告運用、外部制作

この順序で積み上げれば、有料施策に入る前に「自社の強み・訴求・ターゲット」がクリアになっているため、広告のROIも劇的に上がります。

数字を見るタイミング

改善効果は「毎日」ではなく「月次」で判断します。理由は、日次だと曜日変動・季節変動・偶然のノイズが大きすぎて、施策の効果が読み取れないからです。

  • 改善実施日を記録（Googleカレンダーやメモに）
  • 実施前1ヶ月と実施後1ヶ月のCVR・セッション数を比較
  • ±20%以上の変化があれば施策の効果と判断
  • 複数の施策を同月に打つと効果切り分けができないので注意

よくある質問

Q. 集客数と成約率、どちらから改善すべき？
A. 基本はCVRが先。ただし月間セッションが50未満の場合は集客数の底上げから。

Q. CVRが低いのに集客を増やすとどうなる？
A. 問い合わせは少し増えますが、労力の割に成果が出ません。同じ労力でCVR改善のほうが4〜10倍の効率です。

Q. CVRの目安は？
A. 地域集客系なら2〜5%が合格。5%以上なら優秀。0.5%未満は改善余地大です。

Q. 集客数を増やすのに一番コスパがいい方法は？
A. MEO（Googleビジネスプロフィール）です。最短2週間で効果が見え、費用ゼロ。

Q. 両方同時進行は不可能？
A. 不可能ではありませんが、個人事業主では効果測定が難しくなるためおすすめしません。

スケール別・意識すべき指標の変化

事業のフェーズによって、追うべき指標は変わっていきます。

フェーズ月間セッション主戦場KPI
立ち上げ0〜100MEO・SNS導線セッション数
初期成長100〜500CVR整備問い合わせ数
安定期500〜2,000SEO・記事資産CVR・LTV
拡大期2,000超単価向上・広告CPA・売上

「立ち上げ」の段階でCVRを気にしても数字が動かず、逆に「安定期」でセッション数だけ追うのは非効率。今の自分がどのフェーズかを見極めることが、施策判断の起点になります。

アクセスとCVRを同時に押し上げる例外

「CVR先」の原則には、実は例外があります。それが「集客源そのものを変える」施策。例えば、これまで「無料」で流入していた層を、「地域名＋悩み」の検索で流入する層に切り替えると、セッションは減らずにターゲット純度が上がり、CVRが自然に上がります。

  • ブログ記事で「本気で解決したい人」向けキーワードを狙う
  • Instagramの投稿テーマを「憧れ系」から「悩み解決系」にシフト
  • 広告のキーワードを「価格系」から「地域＋悩み系」に切り替え

この場合、CVRと集客数を分けて考えず、「訪問者の質」という1つの指標として同時に改善できます。
